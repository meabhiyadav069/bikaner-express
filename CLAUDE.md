# High-End Restaurant Web Engine Guidelines

## Tech Stack Requirements
- Next.js 15+ (App Router) with TypeScript
- Tailwind CSS with Framer Motion for smooth animations
- Shadcn UI for clean accessible components
- Lucide React for icons
- Sanity.io / Supabase for backend integration

## Design System Rules (Anti-AI Aesthetics)
- Palette: Charcoal (#0F0F10), Warm Dark Graphite (#18181A), Muted Gold (#D4AF37), Soft Off-White (#F4F4F5).
- Typography: Editorial Serif for Headings (Instrument Serif or Playfair Display), Clean Sans-Serif for Body (Plus Jakarta Sans).
- Layout: Asymmetrical grids, high contrast, backdrop blur overlays (backdrop-blur-md), zero generic centered 3-card features.
- Micro-Interactions: Hover scales on buttons, staggered scroll reveals on food items, fluid tab transitions for menus.

## Code Standards
- Use Clean Functional React Components with explicit TypeScript interfaces.
- Mobile-first responsive design for all sections.
- Keep server actions and API routes modular.
